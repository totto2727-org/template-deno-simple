# Deno Simple Template

Create a repository with [Use this template](https://github.com/totto2727-org/template-deno-simple/generate), then use an AI coding agent to initialize it by following [AGENTS.md](./AGENTS.md).

Give the agent your project name, purpose, and intended publication targets, for example:

```text
Read AGENTS.md and initialize this repository according to its instructions.
Project: <owner/repository and package name>
Purpose: <what the project should do>
Publication: <JSR, FlakeHub, or neither>
Customize the project metadata and documentation for this project.
Do not publish packages or enable publishing workflows before the required repository links are configured.
```
